# Canvas to Google Tasks

Automatically exports Canvas assignments over to Google Calendar as <ins>tasks instead of events</ins>.

### Requirements
```
pip3 install google-auth google-auth-oauthlib google-auth-httplib2 google-api-python-client python-dotenv python-dateutil requests
```
