# Canvas to Google Tasks

## Automatically exports Canvas assignments over to Google Calendar as new tasks.

This repository provides a solution for users who want to automatically export their Canvas assignments over to Google Calendar as **tasks instead of events**.

> Google Calendar's current support for exporting assignments over only exports them as events so users aren't able to check mark them off once they completed the assignment. By exporting them over as tasks, this allows users to mark them off and keep track of what assignments are finished or not finished.
