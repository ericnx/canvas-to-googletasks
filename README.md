# Canvas to Google Tasks

Automatically exports Canvas assignments over to Google Calendar as <ins>tasks instead of events</ins>.

### <ins> Credits </ins>
- [OAuth2](https://canvas.instructure.com/doc/api/file.oauth.html)
- [Assignments API](https://canvas.instructure.com/doc/api/assignments.html#method.assignments_api.index)
- [Courses API](https://canvas.instructure.com/doc/api/courses.html)
- [Google Tasks API](https://developers.google.com/tasks/reference/rest)
- [Python quickstart](https://developers.google.com/tasks/quickstart/python) for quick basic usage of the Tasks API
